# Shift Squad

Play at https://ahamze123.github.io/shift-squad/

A 3D jobs simulator in the browser. Pick one of four workplaces from the menu (Corner Shop, Bistro Kitchen, Downtown Office, Auto Garage), grab what each robot customer asks for and hand it over. There is no shift timer and no customer timer.

The whole game is bundled in `index.html`, including the 3D models. Three.js and the fonts load from public CDNs.

Online rooms only work when the game is opened inside Claude; here it runs in solo mode.
