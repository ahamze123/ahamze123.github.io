# Battleship · Naval Command

Play at https://ahamze123.github.io/battleship/

Computer battles and online rooms for two players. Select Online, create a room, then send the invite link to a friend.

The frontend is bundled in index.html. Combat video/audio assets and the persistent room API are served from https://battleship-command.amer234.chatgpt.site. GitHub Pages hosts the playable frontend.
